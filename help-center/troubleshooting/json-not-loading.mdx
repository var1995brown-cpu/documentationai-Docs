---
title: JSON Not Loading
description: How to resolve issues when your JSON fails to display.
---

## Symptoms

- You paste JSON but nothing appears
- Error message: "Invalid JSON format"

## Causes

- Missing or extra commas
- Unclosed brackets/braces
- Non-UTF8 characters

## Quick Fix

<Steps>
  <Step title="Check JSON format">
    Paste your JSON into a text editor and ensure brackets match and syntax is correct.
  </Step>
  <Step title="Validate JSON">
    Use the "Validate" button to identify and fix syntax errors.
  </Step>
  <Step title="Clear and retry">
    If issues persist, click "Clear" and paste only the JSON text again.
  </Step>
</Steps>

## Recent Updates

<Update label="2024-10-15" description="v2.1.0" tags={["feature", "improvement"]}>

## New Features

- Added enhanced search functionality that highlights matches across nested JSON structures.
- Introduced AI-powered suggestions for common JSON fixes, like missing commas or invalid keys.

## Improvements

- Optimized rendering for large JSON files (`>10MB`), reducing load time by 40%.
- Enhanced validation with real-time error tooltips for quicker debugging.

## Bug Fixes

- Fixed collapse/expand state persistence when switching between tabs.
- Resolved issue where beautified output lost custom indentation preferences.

</Update>

<Update label="2024-09-20" description="v2.0.0" tags={["breaking", "feature"]}>

## New Features

- Complete UI redesign with dark mode toggle and resizable panels.
- Added export options: Copy to clipboard, download as `.json` or `.txt`.

## Breaking Changes

- Updated default indentation from 2 to 4 spaces; configure in settings to revert.

## Improvements

- Integrated tree view for hierarchical navigation of JSON objects.
- Performance boost for validation on arrays with thousands of items.

## Bug Fixes

- Corrected parsing errors for JSON with trailing commas in modern browsers.
- Fixed drag-and-drop file upload on mobile devices.

</Update>

<Update label="2024-08-10" description="v1.5.0" tags={["bugfix", "improvement"]}>

## Improvements

- Resolved copy button failure in Safari browsers.

</Update>

## Upgrade Guide

Follow these steps to ensure you experience the latest features:

<Steps>
  <Step title="Clear Cache" icon="refresh-cw">
    Press `Ctrl+Shift+R` (or `Cmd+Shift+R` on macOS) to hard refresh the page.
  </Step>
  <Step title="Update Settings" icon="settings">
    Review your indentation and theme preferences in the settings panel.
  </Step>
  <Step title="Test New Features" icon="play">
    Load a sample JSON and try the search or AI suggestions.
  </Step>
</Steps>
